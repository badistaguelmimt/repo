# Adopty - L'éveil Naturel 🐾

**Adopty** est une plateforme digitale innovante dédiée à la gestion d'un centre d'adoption animalier en Algérie. Notre mission est de centraliser les demandes d'adoption, d'automatiser le matching entre les animaux et les familles, et de sensibiliser à la protection animale.

![Banner](https://images.unsplash.com/photo-1548191265-cc70d3d45ba1?auto=format&fit=crop&q=80&w=1200)

## ✨ Fonctionnalités

- **Encyclopédie des Races** : Apprenez-en plus sur les besoins et le caractère de chaque espèce (Chiens, Chats, Lapins).
- **Catalogue d'Adoption** : Filtrez les animaux par espèce, taille, caractère et besoins spécifiques.
- **Processus d'Adoption Guidé** : Un parcours clair de la première demande à la rencontre au refuge.
- **Gestion de Services** : Réservation de promenades et de pet-sitting via des prestataires certifiés.
- **Dashboard Utilisateur** : Suivi des demandes d'adoption et historique des interactions.
- **Système de Signalement** : Une ligne d'urgence pour signaler les animaux en danger.
- **Boutique Éco-responsable** : Produits bio et durables pour vos compagnons.

## 🛠️ Stack Technique

- **Frontend** : React 18, Vite
- **Styling** : Vanilla CSS & Tailwind CSS (pour certains composants)
- **Animations** : Framer Motion
- **Authentification** : Clerk
- **Icônes** : Google Material Symbols

## 🚀 Installation & Lancement

1.  **Cloner le repo** :
    ```bash
    git clone [VOTRE_URL_GITHUB]
    cd adopty-site
    ```

2.  **Installer les dépendances** :
    ```bash
    npm install
    ```

3.  **Configurer les variables d'environnement** :
    Créez un fichier `.env` à la racine et ajoutez votre clé Clerk :
    ```env
    VITE_CLERK_PUBLISHABLE_KEY=votre_cle_ici
    ```

4.  **Lancer le serveur de développement** :
    ```bash
    npm run dev
    ```
